Questions fréquentes

Combien coûte le déplacement d'un plombier à Saint-Omer ?

Le forfait déplacement est inclus dans le tarif annoncé. 80-100€ TTC pour diagnostic + petit dépannage en heures ouvrées sur Saint-Omer / Dunkerque.

Le devis est-il payant ?

Non, le devis est gratuit. Si vous ne validez pas, vous ne payez rien (sauf expertise complexe annoncée à l'avance).

Acceptez-vous le paiement échelonné ?

Oui, pour les chantiers > 1 500€ TTC : 3-4 fois sans frais. Pour rénovations lourdes : étalement 6-10 mensualités selon dossier.

Êtes-vous éligible aux aides MaPrimeRénov ?

Oui, nos artisans sont labellisés RGE. Nous accompagnons sur le dossier MaPrimeRénov + CEE pour optimiser le reste à charge. → Voir toutes les aides
