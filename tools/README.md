# 🛠 Outils & Scripts

Scripts utilitaires à double-cliquer depuis Finder.

## Installation initiale (à faire une seule fois)

1. **Setup-Git-Auth.command** — Configure le trousseau macOS pour l'auth GitHub (Personal Access Token)
2. **Install-AutoPush.command** — Installe le daemon launchd qui pousse automatiquement toute modification

## Usage quotidien

- **Push-Express.command** — Push manuel rapide (commit auto avec message daté)
- **Push-Auto.command** — Push manuel avec demande de message de commit
- **Débloquer-Git.command** — Si GitHub Desktop est bloqué par un lock Git (rare)

## Désinstallation

- **Uninstall-Auto-Push-Daemon.command** — Retire le service launchd auto-push

## Notes

Les fichiers préfixés `_obsolete-` sont des résidus d'anciennes versions (à supprimer manuellement quand vous êtes sûrs de ne plus en avoir besoin).
