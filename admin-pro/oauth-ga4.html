🔐 Connexion OAuth GA4 — Plan B

Plan B au cas où Google bloque le service account. Au lieu d'un compte robot, on utilise directement ton compte Google (florian.dhaillecourt@helpconfort.com) via OAuth — pas besoin d'autoriser quoi que ce soit dans Property Access Management.

📋 Comment ça marche

1
Tu cliques le bouton bleu ci-dessous → une popup Google s'ouvre
2
Tu choisis ton compte florian.dhaillecourt@helpconfort.com et tu autorises l'accès à GA4 (scope analytics.readonly)
3
Google te redirige avec un code d'autorisation dans l'URL
4
La page échange ce code contre un Refresh Token (à vie tant que tu ne révoques pas)
5
Le Refresh Token est stocké dans app_settings.ga4_oauth et utilisé pour toutes les requêtes GA4 futures

Pré-requis : Client ID + Client Secret GBP (déjà configurés dans Settings → GBP). On réutilise les mêmes credentials Google.

Aucune donnée envoyée à HC tant que tu n'as pas explicitement validé dans la popup Google.
