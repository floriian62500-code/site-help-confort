📊 Assistant Google Analytics 4

Je te guide pour brancher GA4 au dashboard, pour voir tes vraies stats visiteurs (sessions, sources, conversions) directement dans le back-office au lieu d'aller sur le site GA.

⏱️ ~20 min · 🆓 Gratuit · Service Account (jamais expire)
1

Vérifier que GA4 est bien actif sur le site

Pré-requis évident mais à vérifier.

2 min
  1. Ouvre Google Analytics
  2. Choisis la propriété HELP! Confort
  3. Va dans Admin (engrenage en bas) → Property settings
  4. Note ton Property ID (un nombre à 9 chiffres comme 492836271)
Pas encore de propriété ? Crée-la dans GA4 d'abord puis remplace l'ID G-XXXXXXXXXX dans toutes les pages HTML par ton vrai ID GA4. Voir ACTIVER-TRACKING.md.
2

Créer / réutiliser un projet Google Cloud

Tu peux réutiliser le projet "Help Confort Back-Office" créé pour la connexion Google Business.

2 min
  1. Ouvre Google Cloud Console (bouton ci-dessous)
  2. En haut, vérifie que le projet sélectionné est Help Confort Back-Office (sinon clique sur le sélecteur en haut et choisis-le, ou crée-le)
Ouvrir Google Cloud Console
3

Activer la Google Analytics Data API

L'API à activer pour lire les stats programmatiquement.

2 min
  1. Va dans APIs et services → Bibliothèque
  2. Cherche « Google Analytics Data API »
  3. Clique → Activer
Activer Google Analytics Data API
4

Créer un Service Account

Un compte robot qui aura accès à tes stats en lecture seule (plus sécurisé que d'utiliser ton compte perso).

3 min
  1. Va dans IAM & admin → Service Accounts
  2. Clique + Create service account
  3. Remplis :
    • Service account name : ga4-stats-reader
    • Service account ID : se remplit auto
    • Description : Lecture stats GA4 pour back-office
  4. Clique Create and continue
  5. Étape "Grant access" : laisse vide → Continue
  6. Étape "Grant users access" : laisse vide → Done
  7. Note l'email du service account (genre ga4-stats-reader@help-confort-back-office.iam.gserviceaccount.com) — tu en auras besoin à l'étape 6
Ouvrir Service Accounts
5

Créer + télécharger la clé JSON

Le fichier d'authentification du service account.

2 min
  1. Clique sur le service account ga4-stats-reader
  2. Onglet Keys
  3. Clique Add key → Create new key
  4. Type : JSON → Create
  5. Un fichier help-confort-back-office-xxxxx.json se télécharge dans ton dossier Downloads
  6. Ouvre-le avec TextEdit, copie tout le contenu (Cmd+A puis Cmd+C)
🔒 Ce fichier JSON = mot de passe Ne le partage jamais, ne le commit pas dans Git. Si compromis, supprime-le dans Service Accounts → Keys et regénère.
6

Partager ta propriété GA4 avec le service account

Étape critique : sinon le service account verra rien.

3 min
  1. Retourne dans Google Analytics
  2. Choisis la propriété HELP! Confort
  3. Admin (engrenage) → colonne Property → Property Access Management
  4. Clique + (haut droite) → Add users
  5. Email : colle l'email du service account de l'étape 4 (ga4-stats-reader@...iam.gserviceaccount.com)
  6. Rôle : choisis « Viewer » (lecture seule, le minimum nécessaire)
  7. DÉCOCHE "Notify new users by email" (pas la peine de spammer un robot)
  8. Clique Add
🔑 C'est l'étape qui débloque tout Sans ce partage explicite, même avec la bonne clé JSON, l'API te répondra 403.
7

Coller dans le back-office + Tester 🎉

Le bout du tunnel.

2 min

Va dans Paramètres → Google Analytics 4 :

  • Property ID : 492836271 (étape 1, juste le nombre, sans properties/)
  • Service Account Key (JSON) : colle tout le contenu du fichier JSON (étape 5)
Ouvrir Paramètres → GA4
Puis lance le diagnostic :
🎉 Une fois testé OK Le dashboard affichera automatiquement les vraies stats : sessions, sources, top pages, conversions. Le service account ne périme jamais — installation à vie.
