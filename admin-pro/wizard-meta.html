📘 Assistant Meta — Facebook + Instagram

Je te guide pour connecter ta page Facebook « HELP Confort ST OMER » et ton compte Instagram Business à ton back-office. Une fois fait, tu pourras publier sur les 2 réseaux en 1 clic depuis ici, et synchroniser tes posts.

⏱️ ~25 min · 🆓 Gratuit · Token longue durée (60 j + renouvelable)
1

Créer une App sur Meta Developers

L'App te permettra d'obtenir les tokens et de publier via la Graph API.

5 min
  1. Clique sur le bouton ci-dessous pour ouvrir Meta for Developers
  2. Connecte-toi avec le compte Facebook qui administre la page (Florian Dhaillecourt)
  3. En haut à droite, clique Mes Apps → Créer une App
  4. Type d'application : choisis « Business » → Continuer
  5. Nom de l'App : Help Confort Back-Office
  6. Email de contact : ton email pro
  7. Compte Business Manager : ignore (laisse vide) → Créer
Ouvrir Meta for Developers
2

Ajouter les produits Facebook Login + Pages API

2 produits à ajouter au tableau de bord de l'App.

3 min
  1. Dans le menu de gauche de l'App : Ajouter un produit
  2. Trouve Facebook Login for Business → Configurer
  3. Reviens à Ajouter un produit
  4. Trouve Pages API → Configurer (si pas listé, c'est OK, ça vient avec les permissions à l'étape 4)
💡 Pas de panique si "Pages API" n'apparaît pas Meta a fusionné plusieurs APIs. Tant que Facebook Login est ajouté, on peut continuer.
3

Récupérer le Page ID Facebook + IG Business ID

Pour identifier la page et le compte Instagram associé.

3 min

Page ID Facebook :

  1. Va sur ta page HELP Confort ST OMER
  2. Clique sur "À propos" (dans le menu de la page)
  3. Tout en bas, cherche « ID de la page » — un nombre à 15-16 chiffres
  4. Note-le, ce sera ton fb_page_id

Instagram Business Account ID (si tu as un compte Insta Business lié) :

  1. Ton Instagram doit être un compte Professionnel/Créateur, pas perso
  2. Il doit être lié à la Page Facebook ci-dessus (via Meta Business Suite)
  3. L'ID se récupère à l'étape 6 via Graph Explorer (sera affiché automatiquement)
Ouvrir Meta Business Suite
4

Générer un User Access Token via Graph API Explorer

Le User Token est temporaire (1h), on le transformera en Page Token longue durée à l'étape 6.

5 min
  1. Ouvre Graph API Explorer (bouton ci-dessous)
  2. En haut à droite : Meta App → choisis Help Confort Back-Office
  3. Clique Generate Access Token
  4. Coche ces permissions (dans la liste à droite) :
    • pages_show_list
    • pages_read_engagement
    • pages_manage_posts
    • pages_manage_metadata
    • instagram_basic
    • instagram_content_publish
    • business_management
  5. Clique Generate Access Token en bas → connecte-toi → autorise
  6. Le User Access Token (commence par EAA...) s'affiche en haut. Copie-le.
Ouvrir Graph API Explorer
5

Récupérer l'App ID + App Secret

Pour convertir le User Token en token longue durée.

2 min
  1. Dans le tableau de bord de ton App, à gauche : Paramètres → De base
  2. Note App ID (un nombre à 15-16 chiffres)
  3. À côté de App Secret, clique Show → entre ton mot de passe FB → copie le secret
🔒 App Secret = mot de passe Ne le partage jamais publiquement et ne le commit pas dans Git.
Ouvrir mes Apps
6

Échanger contre un Long-Lived User Token + Page Token

Le Page Token n'expire JAMAIS (sauf si tu changes ton mot de passe FB ou révoques l'App).

5 min

6.1 — Long-Lived User Token (60 jours)

  1. Ouvre une nouvelle URL dans ton navigateur (remplace les 3 placeholders par tes valeurs) : 
    https://graph.facebook.com/v21.0/oauth/access_token?grant_type=fb_exchange_token&client_id=TON_APP_ID&client_secret=TON_APP_SECRET&fb_exchange_token=TON_USER_TOKEN
  2. Tu obtiens un JSON avec access_token: EAAxxxxx... — c'est ton Long-Lived User Token

6.2 — Page Access Token never-expiring

  1. Avec le Long-Lived User Token, ouvre : 
    https://graph.facebook.com/v21.0/me/accounts?access_token=TON_LONG_LIVED_USER_TOKEN
  2. Tu obtiens un JSON avec une liste de tes pages. Cherche « HELP Confort »
  3. Le access_token de cette page est ton Page Access Token définitif (jamais expiré)
  4. Note aussi le champ id = ton fb_page_id

6.3 — Instagram Business Account ID

  1. Avec le Page Token, ouvre : 
    https://graph.facebook.com/v21.0/TON_FB_PAGE_ID?fields=instagram_business_account&access_token=TON_PAGE_TOKEN
  2. Tu obtiens instagram_business_account.id — c'est ton ig_business_account_id
🎯 Tu as maintenant 3 valeurs critiques Page Access Token (longue durée) · Page ID Facebook · IG Business Account ID
7

Coller dans le back-office

Paramètres → Facebook & Instagram.

1 min

Va dans Paramètres du back-office, section Facebook + Instagram, et colle :

  • Page Access Token (longue durée) : EAAxxxx... (étape 6.2)
  • Page ID Facebook : 100064xxx... (étape 3 ou 6.2)
  • Instagram Business Account ID : 17841xxx... (étape 6.3, optionnel si pas d'Insta)
Ouvrir Paramètres → Meta
8
