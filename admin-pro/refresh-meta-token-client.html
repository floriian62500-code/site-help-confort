🔁 Renouveler le token Facebook (permanent)

Échange ton Page Access Token courte durée contre un token long-lived (60 jours) puis le transforme en Page Access Token permanent (à vie tant que tu restes admin de la page). Tout se passe côté client, pas d'Edge Function.

Comment ça marche
  1. Lit ton App ID + App Secret + token actuel depuis app_settings.meta
  2. Appelle /oauth/access_token?grant_type=fb_exchange_token → long-lived user token (60 jours)
  3. Appelle /me/accounts avec ce long-lived → récupère le Page Access Token permanent
  4. Sauvegarde le nouveau token en base (et logue l'expiration via debug_token)

Aucune action manuelle — tout côté client.
