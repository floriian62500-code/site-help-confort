📋 Comment retrouver le JSON ?

1. Va sur Google Cloud Console → Service accounts
2. Clique sur ga4-reader@help-confort-back-office.iam.gserviceaccount.com
3. Onglet "Clés" (Keys)
4. "Ajouter une clé" → "Créer une clé" → JSON
5. Un fichier .json est téléchargé. Ouvre-le avec TextEdit. Cmd+A puis Cmd+C → colle ici.

2️⃣ Clé API Claude IA À COMPLÉTER

Récupère ta clé sur console.anthropic.com → API Keys. Format : sk-ant-api03-... (environ 108 caractères).

🔑 Cette clé sert à quoi ?

• Réponse automatique aux avis Google ≤ 2★ (brouillons à valider)
