💼 Assistant LinkedIn

Je te guide pour connecter ta page LinkedIn entreprise. Tu pourras ensuite publier des Posts en 1 clic depuis le back-office (chantiers, actualités, photos avant/après).

⏱️ ~20 min · 🆓 Gratuit · Access Token 60 jours (renouvelable)
1

Créer une App LinkedIn Developers

L'App te permettra de publier via l'API officielle.

5 min
  1. Connecte-toi à LinkedIn avec le compte qui administre la Page Entreprise
  2. Clique sur le bouton ci-dessous pour ouvrir LinkedIn Developers
  3. Clique Create app
  4. Remplis :
    • App name : Help Confort Back-Office
    • LinkedIn Page : choisis ta page entreprise « HELP Confort »
    • App logo : upload le logo HC (carré 100×100 minimum)
    • Legal agreement : coche
  5. Clique Create app
Ouvrir LinkedIn Developers
2

Vérifier la propriété de la Page

LinkedIn demande de prouver que tu administres la page entreprise.

2 min
  1. Dans l'app : onglet Settings
  2. Section Verify → clique Verify
  3. Une URL est générée → copie-la
  4. Ouvre cette URL dans ton navigateur (tu seras connecté en tant qu'admin LinkedIn) → clique Verify
  5. Reviens dans l'app → ✓ Verified
3

Demander les produits Share + Sign In

2 produits à demander pour pouvoir publier.

2 min
  1. Onglet Products
  2. Cherche « Share on LinkedIn » → Request access (instantané)
  3. Cherche « Sign In with LinkedIn using OpenID Connect » → Request access (instantané)
  4. Cherche « Community Management API » → Request access (peut prendre 1-3 jours pour approbation manuelle)
⏱️ Community Management API : approbation manuelle Cette API permet de publier sur la Page (pas seulement sur ton profil perso). LinkedIn la vérifie en 1-3 jours ouvrés. Tu reçois un mail.
4

Récupérer Client ID + Client Secret

Pour générer ton OAuth Access Token.

1 min
  1. Onglet Auth
  2. Note ton Client ID (un nombre)
  3. À côté de Client Secret, clique sur l'œil 👁 → copie
🔒 Client Secret Aussi sensible qu'un mot de passe — ne jamais commit dans Git.
5

Configurer l'URL de redirection OAuth

Pour le flow d'authentification.

1 min
  1. Toujours dans Auth
  2. Section OAuth 2.0 settings → Authorized redirect URLs for your app
  3. Clique Add redirect URL
  4. Colle : https://www.linkedin.com/developers/tools/oauth/redirect (l'URL officielle du Token Generator LinkedIn)
  5. Save
6

Générer l'Access Token via OAuth Tools

LinkedIn fournit un outil pour générer le token sans coder.

5 min
  1. Ouvre OAuth 2.0 Tools (bouton ci-dessous)
  2. Choisis ton App Help Confort Back-Office
  3. Coche les scopes :
    • r_liteprofile ou openid + profile
    • w_member_social
    • w_organization_social (pour publier sur la Page)
    • r_organization_social (pour lire les posts)
    • rw_organization_admin (gestion Page)
  4. Clique Request access token
  5. LinkedIn t'autorise → te redirige → tu obtiens un access_token
  6. Copie-le (commence par AQ... en général, valable 60 jours)
Ouvrir OAuth 2.0 Token Generator
7

Récupérer l'Organization URN

L'identifiant unique de ta page LinkedIn entreprise.

2 min

Méthode 1 (via URL) :

  1. Va sur ta page LinkedIn entreprise (page « HELP Confort »)
  2. Onglet Admin tools → Manage admins (ou regarde l'URL)
  3. L'URL ressemble à https://www.linkedin.com/company/12345678/admin/ — le nombre 12345678 est ton Organization ID
  4. Préfixe avec urn:li:organization: → tu obtiens urn:li:organization:12345678

Méthode 2 (via API, si méthode 1 ne marche pas) :

  1. Ouvre cette URL (remplace le token) : 
    https://api.linkedin.com/v2/organizationAcls?q=roleAssignee&role=ADMINISTRATOR&projection=(elements*(organization~(id,localizedName)))
&Authorization: Bearer TON_ACCESS_TOKEN
  2. Tu vois id: 12345678 et localizedName: "HELP Confort"
8

Coller + Tester 🎉

Dernière ligne droite.

2 min

Va dans Paramètres → LinkedIn et colle :

  • Access Token : AQxxxxx... (étape 6)
  • Organization URN : urn:li:organization:12345678 (étape 7)
Ouvrir Paramètres → LinkedIn
