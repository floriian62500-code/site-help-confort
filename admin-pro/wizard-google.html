🌐 Assistant Connexion Google Business

Je te guide pas à pas pour connecter tes 2 fiches Google Business Profile (Saint-Omer + Dunkerque) au back-office. Une fois fait, tu pourras répondre aux avis Google et publier des Posts directement depuis ici.

⏱️ ~25 min · 🆓 Gratuit
1

Créer un projet Google Cloud

Google demande qu'on passe par leur Cloud Console pour activer les APIs.

5 min
  1. Clique sur le bouton ci-dessous pour ouvrir Google Cloud Console
  2. Connecte-toi avec le compte Google qui gère tes fiches Business Profile (pas un autre compte)
  3. En haut de la page, clique sur le sélecteur de projet → "Nouveau projet"
  4. Nom du projet : Help Confort Back-Office
  5. Clique Créer et patiente 30 secondes
  6. Vérifie que le projet sélectionné en haut est bien Help Confort Back-Office
Ouvrir Google Cloud Console
2

Activer les 2 APIs Business Profile

2 APIs à activer dans la bibliothèque.

3 min
  1. Va dans APIs et services → Bibliothèque (menu hamburger en haut à gauche)
  2. Cherche puis active My Business Account Management API
  3. Cherche puis active My Business Business Information API
⚠️ NE PAS activer "Google My Business API" Cette API est obsolète depuis fin 2024 (deprecated par Google).
Ouvrir la bibliothèque d'APIs
3

Demander l'accès aux APIs

Étape importante — Google demande une autorisation manuelle.

15 min · async
💡
Cette étape ne te bloque PAS. Google approuve sous 7 à 10 jours ouvrés. Pendant ce temps, continue les étapes 4 à 8 — quand l'approbation arrive, tout fonctionnera automatiquement.
⏱️ Délai d'approbation Google : 7 à 10 jours ouvrés Sans cette approbation, les API renverront des erreurs 403. Mais le reste (OAuth, IDs, tokens) marche en parallèle.

4

Configurer l'écran OAuth

Définit comment ton app demandera les permissions Google.

3 min
  1. Va dans APIs et services → Écran de consentement OAuth
  2. Choisis "Externe" → Créer
  3. Remplis :
    • Nom de l'application : Help Confort Back-Office
    • Email d'assistance utilisateur : ton email
    • Domaines autorisés : helpconfort.com
    • Email du développeur : ton email
  4. Champs d'application → ajouter https://www.googleapis.com/auth/business.manage
  5. Utilisateurs test → ajouter ton email Google
  6. Valide tout
Ouvrir l'écran OAuth
5

Créer les identifiants OAuth

Génère ton Client ID + Client Secret.

3 min
  1. Va dans APIs et services → Identifiants
  2. Clique + Créer des identifiants → ID client OAuth
  3. Type d'application : Application Web
  4. Nom : Help Confort Back-Office
  5. URI de redirection autorisée : https://developers.google.com/oauthplayground
  6. Clique Créer
  7. Une popup affiche ton Client ID et Client Secret
💾 Garde précieusement ces 2 valeurs On en aura besoin à l'étape 6 et plus tard pour configurer le back-office.
Créer les identifiants
6

Générer le Refresh Token

Via l'OAuth Playground officiel Google.

5 min
  1. Ouvre OAuth Playground
  2. Clique l'icône ⚙️ paramètres en haut à droite
  3. Coche "Use your own OAuth credentials" et colle ton Client ID + Client Secret
  4. Dans Step 1, tape ce scope : 
    https://www.googleapis.com/auth/business.manage
  5. Clique Authorize APIs → connecte-toi avec ton compte Google qui gère les fiches
  6. Google affiche un avertissement "non vérifiée" → Paramètres avancés → Accéder
  7. De retour dans Playground, Step 2 → clique Exchange authorization code for tokens
  8. Tu vois Access token ET Refresh token apparaître
🔑 Le Refresh Token est le plus important Il a une durée illimitée. L'Access Token expire en 1h mais l'Edge Function le régénère auto via le Refresh Token.
Ouvrir OAuth Playground
7

Récupérer les IDs comptes + locations

Pour identifier tes fiches Saint-Omer et Dunkerque.

5 min

Dans OAuth Playground (toujours ouvert), Step 3 :

  1. Dans le champ "Request URI", tape : 
    https://mybusinessaccountmanagement.googleapis.com/v1/accounts
  2. Clique Send the request
  3. Dans la réponse JSON, trouve l'name de "Dépan'Audo" (genre accounts/123456789012345)
  4. Copie cette valeur complète — c'est ton account_id_audo

Ensuite, dans Request URI :

https://mybusinessbusinessinformation.googleapis.com/v1/accounts/123456789012345/locations?readMask=name,title
  1. Remplace 123456789012345 par TON numéro de compte
  2. Send the request
  3. Note les name pour Saint-Omer (location_id_st_omer) et Dunkerque (location_id_dk)
8

Coller dans le back-office

7 valeurs à placer dans Paramètres → Google Business Profile.

2 min

Va dans Paramètres du back-office, section Google Business Profile, et colle dans l'ordre :

  • Client ID OAuth : 123456...apps.googleusercontent.com (étape 5) *
  • Client Secret OAuth : GOCSPX-xxxx... (étape 5) *
  • Access Token (OAuth Google) : ya29.xxxx... (étape 6)
  • Refresh Token : 1//xxxx... (étape 6) *
  • Account ID (Dépan'Audo) : accounts/123... (étape 7)
  • Location ID Saint-Omer : locations/123...
  • Location ID Dunkerque : locations/987...
⚠️ Client ID + Client Secret obligatoires Sans eux, l'access token ne pourra pas être renouvelé automatiquement (il expire en 1h). Tu serais obligé de refaire la manip OAuth Playground chaque heure.
Ouvrir Paramètres → GBP
