# DIRECTION VISUELLE — architecture / maîtrise d'œuvre, pas "site IA"

Retour Florian : la proposition précédente est refusée. Trop de cartes colorées, trop "site IA", pas assez premium, pas assez contemporain.

## Nouvelle référence esthétique

Se baser sur les codes des meilleurs sites d'architectes / maîtres d'œuvre / studios d'architecture :
- grands visuels plein cadre ;
- photographie comme matière principale ;
- palette très sobre (blanc cassé, graphite, noir, beige/minéral) ;
- cyan HELP et orange uniquement comme accents fonctionnels ;
- grande typographie éditoriale ;
- grilles rigoureuses ;
- beaucoup d'espace négatif ;
- lignes fines, numérotation, légendes ;
- sections asymétriques mais très structurées ;
- micro-animations discrètes ;
- aucune accumulation de cartes colorées standard ;
- pas de "dashboard look".

## Références de patterns
Étudier les codes suivants sans copier :
- portfolio d'architecte éditorial minimal ;
- hero photo plein écran / full bleed ;
- liste de services numérotée type sommaire d'architecte ;
- projets/interventions comme études de cas ;
- galerie narrative, pas simple grille de tuiles ;
- données techniques discrètes en ligne (zone, délai, métier, type d'intervention) ;
- section "notre approche" en gros texte éditorial ;
- alternance photo pleine largeur / texte très court ;
- CTA sobres, intégrés à la composition ;
- footer architectural très simple.

## Direction HELP CONFORT à prototyper

### Hero accueil
- photo forte d'une vraie intervention ou intérieur contemporain ;
- logo HELP discret mais net ;
- titre très grand : "Un seul interlocuteur. Tous vos travaux."
- sous-titre court : dépannage, maintenance, rénovation à Saint-Omer et sur le littoral ;
- deux actions maximum : Urgence / Découvrir nos métiers ;
- aucun pavé de 6 cartes sous le hero.

### Bloc métiers
Présenter les métiers comme un index éditorial :
01 Plomberie
02 Chauffage
03 Électricité
04 Serrurerie
05 Menuiserie
06 Vitrerie
07 Rénovation
08 Sols & carrelage
Chaque ligne peut révéler une image au survol desktop et une miniature sur mobile.

### Bloc réalisations / interventions
- 3 à 5 grandes photos, ratios différents ;
- légendes fines ;
- "Saint-Omer — remplacement chaudière — 2026" ;
- éventuellement before/after sur un seul cas.

### Particuliers / professionnels
Pas deux grosses cartes colorées. Faire deux chapitres éditoriaux avec photo + texte.

### Preuves
Avis, délai, zone, réseau HELP : petites données/chiffres, pas icônes géantes.

### Couleurs
- fond : #F5F3EE / blanc cassé ;
- texte : #111 / graphite ;
- gris minéral ;
- cyan HELP en accent ;
- orange uniquement pour urgence/CTA principal.
Pas de rainbow métiers sur toute la page.

### Typographie
Tester une combinaison type :
- display/editorial : Manrope / Sora / DM Sans / Space Grotesk selon rendu ;
- texte : Inter/Manrope.
Grande échelle typographique, peu de graisse inutile.

Créer une nouvelle maquette accueil uniquement, depuis main courant, sans toucher prod :

Si la maquette contient encore une succession de petites cartes multicolores standardisées, elle est refusée d'office.
