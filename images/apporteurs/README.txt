LOGOS OFFICIELS DES APPORTEURS D'AFFAIRES
------------------------------------------
Glisser-déposer les logos officiels dans ce dossier avec ces noms exacts
(sensible à la casse, en minuscules) :

- help-confort.png   → Réseau HELP! Confort
- homeserve.png      → HomeServe
- dynaren.png        → Dynaren (l'après-sinistre responsable)
- viaren.png         → ViaREN
- domus.png          → DOMUS (Vie Quotidienne)
- imh.png            → IMH — Groupe IMA
- axa.png            → AXA
- laposte.png        → La Poste — Services à l'habitat

Format recommandé : PNG transparent, hauteur ~80-200 px, poids < 100 Ko.
Une fois les fichiers en place, ils s'affichent automatiquement
dans le bandeau défilant de la page d'accueil.

Si un fichier est manquant ou mal nommé, la pillule correspondante est
automatiquement masquée (vérification via Image() preload).

Pour ajouter d'autres apporteurs : passe par /admin/ → "Apporteurs d'affaires"
